# Changelog
All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-07
### Added
- Complete event-driven multi-agent orchestration via LangGraph.
- Vector semantic search over Milvus.
- Metadata and RBAC layer over PostgreSQL.
- Distributed checkpoint memory via Redis.
- Video analysis pipeline over S3 and VLM.
- End-to-End OpenTelemetry tracing.
- Docker Compose local stack with Jaeger, Prometheus, Grafana.
- Production deployment architectures documented.
