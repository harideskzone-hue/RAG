# 🏛️ VISTA AI — Complete Technical Architecture & System Specification

This document details the architectural design, data flows, persistence mechanisms, security model, and Agentic RAG verification system of VISTA AI.

---

## 1. Pipeline Overview

VISTA AI operates a continuous 5-stage lifecycle for physical security video intelligence:

```
[1. RTSP Chunker] ➔ [2. Auto Ingest Daemon] ➔ [3. CV & Re-ID Pipeline] ➔ [4. Multi-Store Audit] ➔ [5. Agentic RAG Search]
```

---

## 2. Component Specifications

### 2.1 24/7 RTSP Stream Chunker (`scripts/cctv_stream_chunker.py`)
- **Input**: Live RTSP stream (`rtsp://<user>:<pass>@<ip>:554/...`) or local video files.
- **Segmentation**: Slices video into seamless 10-minute MP4 segments (`segment_duration_sec=600`).
- **Telemetry**: Records expected vs received frames, dropped frames, actual FPS, and resolution.
- **Atomic Promotion**: Writes to `input/recording/temp_<cam_id>_<timestamp>.mp4` and atomically renames to `input/watch/<cam_id>_<timestamp>.mp4` once closed.

---

### 2.2 Auto Ingestion Daemon (`scripts/auto_ingest_daemon.py`)
- **State Machine**: Maintains durable segment state transitions:
  `READY` $\rightarrow$ `PROCESSING` $\rightarrow$ `CV_COMPLETE` $\rightarrow$ `PERSISTING` $\rightarrow$ `VERIFYING` $\rightarrow$ `VERIFIED` $\rightarrow$ `CLEANUP_PENDING` $\rightarrow$ `COMPLETED`
- **Idempotency**: Computes SHA-256 hash of each video segment; skips duplicates cleanly.
- **Startup Reconciliation**: Scans `input/processing/` upon daemon restart and safely resumes or cleans up interrupted jobs.

---

### 2.3 Computer Vision Pipeline (`app/cv/`)
- **Person Detection**: YOLO26n / NVIDIA PeopleNet (`conf >= 0.50`).
- **Multi-Object Tracking**: ByteTrack / BoT-SORT (assigns persistent `P001`, `P002`, ... track IDs).
- **Crop Quality Gate** (`app/cv/identity/quality.py`):
  - Filters out blurry (`Laplacian var < 30.0`), too dark (`brightness < 30`), too bright (`brightness > 230`), or tiny crops (`w < 32`, `h < 64`).
  - Selects top 5–8 high-resolution keyframe crops per person track.
- **Person Re-ID** (`app/cv/reid/`):
  - OSNet MSMT17 / SOLIDER TAO Re-ID extractor generates 512-dimensional L2-normalized feature vectors.
- **Identity Resolver** (`app/cv/identity/resolver.py`):
  - Searches Qdrant / Native Vector Store using Cosine Distance.
  - Match Threshold: `0.82` ($\ge 0.82 \rightarrow$ `MATCHED`).
  - Ambiguity Margin: `0.05` (if top 2 matches are within 0.05 margin $\rightarrow$ preserves `UNRESOLVED`).

---

### 2.4 Multi-Store Persistence & Referential Audit (`scripts/cross_store_audit.py`)
1. **PostgreSQL** (*Source of Truth*): Identities, tracks, evidence, video segments, camera registry.
2. **MongoDB** (*Telemetry & Observations*): Observation history, spatial zones, behavior attributes, events.
3. **Qdrant / Native Vector Store** (*Vector Search*): 512-D person feature embeddings.
4. **Object Storage / Filesystem** (*Visual Evidence*): Keyframe crops, person gallery crops, sliced event clips, dynamic JSON metadata (`dataset/metadata/<video_id>.json`).

---

### 2.5 Zero-Hallucination Agentic RAG (`app/graph/supervisor/`)
- **Hybrid Intent Classifier**: Categorizes query intent (`PERSON_SEARCH`, `CAMERA_STATUS`, `EVENT_SEARCH`, `REPORT`).
- **Deterministic Evidence Retrieval**: Fetches structured metadata from PostgreSQL/MongoDB and vector embeddings from Qdrant.
- **VerifiedResultContract**: Authoritative contract generated by the `VerificationAgent` enforcing count integrity and query constraint matching.
- **LLM Reasoning & Grounding Validator**: Synthesizes natural language answer strictly grounded in physical evidence.
